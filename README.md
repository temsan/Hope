# Галерея работ Надежды

Сайт «Надежда Жди»: прокрутка — пролёт сквозь картины Надежды Терёшкиной, в конце — галерея с палитрой.

Сайт: https://temsan.github.io/Hope/ (GitHub Pages из ветки `main`).

## Как устроено

- `index.html` — весь сайт. Каждый переход между картинами — видеоклип, который проигрывается кадр за кадром
  вслед за прокруткой; последний клип — влёт в галерею. Кнопка «сразу в галерею» пропускает пролёт.
- В галерее колесо над картиной её приближает, над палитрой — листает картины.
- «Раскрутить свою» в галерее открывает мастерскую (`assets/studio.js`): капли и мазки красок на холсте, потом холст
  вращается, и краску разносит лучами, как в технике Надежды. Готовое можно сохранить в PNG.
- `assets/ripple.js` — рябь на воде на первом экране и в галерее (WebGL).
- `images/` — картины в оригинале, `images/medium/` — для показа в галерее (1400 px), `images/thumbs/` — миниатюры;
  `images-thumbs.js` — список для галереи. Средние грузятся заранее, оригинал — только когда картину приближают.
- `assets/stills/` — стоп-кадры картин 16:9 (картина с размытыми полями) и `edges.js` — их средние цвета.
- `assets/transitions/t01…t09.mp4` — клипы переходов; каждый кадр ключевой, чтобы прокрутка вставала на любой.

Открыть локально — просто `index.html` в браузере, сервер не нужен.

## Клипы переходов

- `gen_transitions.py` — стоп-кадры `assets/stills/` из картин.
- `import_kling.py` — клип Kling на место перехода: вписан в кадр 16:9, перекодирован для перемотки.
- `ltx_transitions.py` — переходы и влёт локальной видеомоделью LTX-Video (GGUF, хватает 4 ГБ видеопамяти).
- `capture_room.cjs` — снимок комнаты галереи для ключевого кадра влёта (`npm install`, затем `npm run room`).
